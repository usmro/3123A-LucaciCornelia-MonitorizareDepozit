# Monitorizare Depozit

Proiect realizat în C++ pentru gestionarea unui depozit.

## Build proiect

Pentru a compila proiectul, rulează comanda make în terminal, în directorul principal al proiectului. 
Aceasta va compila automat toate fișierele sursă și va genera executabilul aplicației.

## Run proiect

După ce compilarea s-a finalizat cu succes, rulează aplicația folosind comanda ./app. 
Aceasta va porni programul, va avea loc interacționarea cu sistemul de gestionare al depozitului.
